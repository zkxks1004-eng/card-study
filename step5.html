이 단계에서 하는 일

Claude(Anthropic이라는 회사가 만든 AI, 사람처럼 판단하는 컴퓨터 프로그램)가 고객 정보 DB와 카드 정보 DB를 읽습니다.

둘을 비교해 판단한 뒤, 고객이 보는 화면에 어울리는 카드를 추천합니다.

쉬운 비유

손님 주문서와 메뉴판을 둘 다 읽은 점원이 "손님께는 이 메뉴가 잘 맞겠어요"라고 권해 주는 것과 같습니다.

실제 프로젝트에서는

Claude API(프로그램이 Claude에게 일을 맡기는 연결 창구)를 썼습니다.

Claude가 두 DB(데이터베이스, 정보 창고)를 자동으로 읽고 비교해 판단합니다.

그 결과가 고객이 보는 화면에 카드 추천으로 나타납니다.

용어 풀이
용어쉬운 뜻
AI사람처럼 읽고 판단하도록 만든 컴퓨터 프로그램입니다.
ClaudeAnthropic이라는 회사가 만든 AI입니다.
API프로그램끼리 정해진 방식으로 부탁하고 답을 받는 창구입니다. 식당의 주문 창구와 비슷합니다.
API 키API를 쓸 때 필요한 비밀 열쇠입니다. 남에게 보여 주거나 공개된 곳에 올리면 안 됩니다.
맞히기 퀴즈

보기를 누르면 정답과 해설이 나옵니다.

1. 고객이 입력 화면에 적은 내용은 처음에 어디에 쌓일까요?

정답은 ② 구글 시트입니다. 입력한 내용은 먼저 구글 시트에 자동 저장되고, 그다음 SQL DB로 옮겨집니다.

2. 카드 정보는 어디에서 왔을까요?

정답은 ③입니다. 카드 정보는 크롤링(웹사이트 정보를 자동으로 모으는 것)으로 미리 모아 둔 다른 DB에 들어 있었습니다.

3. 두 DB를 읽고 비교해서 카드를 추천하는 것은 누구일까요?

정답은 ① Claude API입니다. 트리거는 2단계의 자동 저장을 돕는 장치이고, 비교와 판단은 Claude가 맡습니다.
