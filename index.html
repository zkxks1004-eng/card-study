DB(데이터베이스, 정보를 정리해 보관하는 창고)가 두 개라는 점이 핵심입니다. 고객 정보 창고와 카드 정보 창고를 AI가 같이 봅니다.

단계별로 보기
  • 1단계 입력 화면과 구글 시트
    고객이 화면에 정보를 적고, 그 내용이 온라인 표에 쌓입니다.
  • 2단계 자동 저장
    사람이 손으로 옮기지 않아도 저장되게 만든 장치입니다.
  • 3단계 SQL DB
    표에 쌓인 정보를 더 튼튼한 창고로 옮깁니다.
  • 4단계 카드 정보 DB 비교
    미리 모아 둔 카드 정보 창고가 따로 있습니다.
  • 5단계 Claude API 추천
    AI가 두 창고를 읽고 비교해서 카드를 추천합니다.
